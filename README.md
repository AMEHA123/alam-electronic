# عالم إلكترونيك

واجهة متجر إلكتروني عربي متجاوبة (RTL) مبنية بـ **HTML وCSS وJavaScript**، دون إطار عمل أو خادم خلفي.

## المزايا

- تصميم متجاوب للهاتف والكمبيوتر.
- واجهة عربية واتجاه من اليمين إلى اليسار.
- تصفية المنتجات والبحث عنها.
- سلة مشتريات تجريبية تحفظ العناصر في `localStorage`.
- أقسام، مقالات، ونموذج اشتراك تجريبي.
- لا توجد مكتبات أو خطوات بناء مطلوبة.

## التشغيل محليًا

1. حمّل أو انسخ ملفات المشروع.
2. افتح `index.html` في المتصفح.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا في GitHub باسم `alam-electronic`.
2. ارفع الملفات: `index.html` و`style.css` و`script.js` و`README.md` إلى جذر المستودع.
3. افتح **Settings** ثم **Pages**.
4. من **Build and deployment** اختر: `Deploy from a branch`.
5. اختر فرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر دقائق قليلة، ثم افتح رابط GitHub Pages الذي يظهر في الصفحة.

## تنبيه

هذا مشروع واجهة تجريبي. لا يحتوي على دفع حقيقي أو قاعدة بيانات أو نظام مستخدمين. لربطه بمتجر فعلي، أضف Backend آمنًا وبوابة دفع مناسبة، ولا تضع مفاتيح الدفع السرية داخل JavaScript أو مستودع GitHub.

## تخصيص سريع

- المنتجات: عدّل مصفوفة `products` في `script.js`.
- الاسم وبيانات التواصل: عدّل `index.html`.
- الألوان والتصميم: عدّل متغيرات CSS أعلى `style.css`.
